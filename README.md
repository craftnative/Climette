# CLIMETTE

> *"Mismo clima, distintas sensaciones"*

## Descripción

CLIMETTE es un producto enfocado en resolver la desconexión entre los datos meteorológicos objetivos y la toma de decisiones prácticas al vestir. Mientras que las herramientas climáticas convencionales se limitan a suministrar variables físicas cuantitativas (como temperatura, humedad o velocidad del viento), CLIMETTE aborda la sensación térmica como una experiencia subjetiva determinada por factores individuales como el metabolismo basal, el historial de confort y la combinación de capas del atuendo.

A través de la calibración de un Índice Térmico Personalizado (ITP) y un modelo de retroalimentación de bucle cerrado (*closed-loop feedback*), el sistema vincula las condiciones ambientales hiperlocales con las percepciones reales de confort de cada persona, eliminando la incertidumbre matutina al seleccionar qué vestir.
